# Sales-Email Agent For Quantum Retail

**Client industry:** healthcare · **Year:** 2024 · **Category:** llm_apps

## Problem
The client needed a sales-email agent because their team was spending too much time on manual work and the existing tooling did not scale.

## What I built
I designed and shipped the solution end to end using LangChain, an async Python web API, Pinecone. I worked directly with the client's product manager and delivered in 7 weeks.

## Result
The system raised conversion by 14%. The client extended the contract for a second phase.
