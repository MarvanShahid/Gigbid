# Ppe Compliance Camera For Homestead

**Client industry:** edtech · **Year:** 2023 · **Category:** computer_vision

## Problem
The client needed a PPE compliance camera because their team was spending too much time on manual work and the existing tooling did not scale.

## What I built
I designed and shipped the solution end to end using MLOps, computer vision, an async Python web API, containerised services, a dynamic-graph deep learning framework. I worked directly with the client's ops lead and delivered in 7 weeks.

## Result
The system reduced latency from 1181 ms to 96 ms. The client extended the contract for a second phase.
