# Fitness Tracker App For Corvid Labs

**Client industry:** logistics · **Year:** 2023 · **Category:** mobile

## Problem
The client needed a fitness tracker app because their team was spending too much time on manual work and the existing tooling did not scale.

## What I built
I designed and shipped the solution end to end using a typed query API, React Native, OAuth. I worked directly with the client's founder and delivered in 5 weeks.

## Result
The system handled 37k requests per day. The client extended the contract for a second phase.
