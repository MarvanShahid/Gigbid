# Collaborative Editor For Homestead

**Client industry:** fintech · **Year:** 2026 · **Category:** realtime_apps

## Problem
The client needed a collaborative editor because their team was spending too much time on manual work and the existing tooling did not scale.

## What I built
I designed and shipped the solution end to end using TypeScript, Celery, AWS, Django, a JavaScript backend runtime. I worked directly with the client's founder and delivered in 3 weeks.

## Result
The system handled 30k requests per day. The client extended the contract for a second phase.
