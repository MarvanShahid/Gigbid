# Clinic Booking App For Bluepeak

**Client industry:** edtech · **Year:** 2023 · **Category:** mobile

## Problem
The client needed a clinic booking app because their team was spending too much time on manual work and the existing tooling did not scale.

## What I built
I designed and shipped the solution end to end using OAuth, React Native, a typed query API. I worked directly with the client's founder and delivered in 8 weeks.

## Result
The system handled 15k requests per day. The client extended the contract for a second phase.
