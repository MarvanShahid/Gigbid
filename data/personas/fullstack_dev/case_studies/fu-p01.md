# Subscription Box Shop For Sagebrush

**Client industry:** e-commerce · **Year:** 2023 · **Category:** ecommerce

## Problem
The client needed a subscription box shop because their team was spending too much time on manual work and the existing tooling did not scale.

## What I built
I designed and shipped the solution end to end using React, Tailwind CSS, Next.js, a typed query API. I worked directly with the client's ops lead and delivered in 5 weeks.

## Result
The system handled 25k requests per day. The client extended the contract for a second phase.
