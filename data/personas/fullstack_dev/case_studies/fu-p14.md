# Chat Support Widget For Willow Learning

**Client industry:** logistics · **Year:** 2022 · **Category:** realtime_apps

## Problem
The client needed a chat support widget because their team was spending too much time on manual work and the existing tooling did not scale.

## What I built
I designed and shipped the solution end to end using a JavaScript backend runtime, TypeScript, React, AWS, a background task queue on Redis. I worked directly with the client's CTO and delivered in 11 weeks.

## Result
The system reduced latency from 1678 ms to 187 ms. The client extended the contract for a second phase.
